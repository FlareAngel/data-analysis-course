## 测试口径

每题的 `reference.py` 独立运行、结果回填 `task.json`；此外人为设置一个典型错误时间理解（如 UTC 日代替本地日、把截止日计入、取创建时间而非确认时间等），逐题检查此错误是否导致最终答案不同。该对照不是 Agent 的真实失败率。

CSV 中地区编码使用 NE、N-E 等，不直接出现中文“东北”；数据中包含边界值、同义状态和值类型差异，但不包含针对 Agent 的恶意系统指令。

## 注意

部分 Task 会涉及非常长的 JSON 答案数组，直接比较时应遵守 `task_statement` 中的数据类型和排序规则。所有数据为合成数据，金额和运营指标仅用于分析训练。
